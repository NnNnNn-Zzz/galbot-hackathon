# drawer_calib — 抽屉实验点位生成与标定的离线工具链

这套脚本产出 `scenes/scene_medicine_check/pipeline/configs/teach_drawer_real.json` 里
`VIA_CARRY_P2_*` / `VIA_P2_P1_*` / `VIA_P1_P0_*` 共 34 个中间点，以及 P0/P1/P2 三个实测点的
标定后末端位姿。**纯离线、零副作用**（只读 URDF 与标定 JSON），不连机器人。

## 为什么需要它

真机上「同一末端位姿、不同关节解」是实锤（规划器随机选 IK 分支，贴限位的分支直接 FAULT）。
所以不能靠"给两个端点让规划器自己插"，必须**离线把每段切成单步 ≤15° 的构型序列**，
再逐点做关节回放。这套脚本就是干这件事的。

## 文件

| 文件 | 作用 |
|---|---|
| `galbot_one_golf.urdf` | 从 HPU `/userdata/update/manual_update/share/whole_body_control/config/teleop/longarm/wbc_ik/` 取回的 URDF |
| `fk_fix.py` | URDF 解析 + FK 链拼接 |
| `fk_reach_3pts.py` | 单点标定（`calibrate()` → 平移偏置 + 常量姿态修正）+ 数值 IK |
| `_gen_teach_real.py` | 由 `WAYPOINTS.json` 生成 P0/P1/P2 实测点位并写回 configs |
| `_plan_carry_p2_p1_p0.py` | **主工具**：按 CARRY→P2→P1→P0 逐段规划中间点 |
| `WAYPOINTS.json` | P0/P1/P2 的实测 7 关节角（50/20/20 帧均值） |
| `sdk_snapshot.json` | 标定快照：一组已知 (关节角, TCP) 对，用来反解 URDF 的系统偏差 |

## 用法

```bash
# 在仓库根运行
python tools/drawer_calib/_plan_carry_p2_p1_p0.py           # 只看方案
python tools/drawer_calib/_plan_carry_p2_p1_p0.py --write   # 写进 teach_drawer_real.json
```

`--write` 会先删掉旧的 `JNT_ENTRY_*` / `JNT_P0_P1_*`（方向作废的那批），再写入新点。

## 方法

每段在两种插值之间**自动选优**：

1. **末端直线 + 姿态 slerp + 上一点解作下一点 IK 种子**（保证 IK 分支连续）
2. **关节线性插值**（两端合法则线段必合法，但末端不走直线）

排序依据：限位余量（硬线 2°）→ TCP 占位盒命中数 → 最低 z → 单步跨度。

历史结论（写在代码里以防重复踩）：

- `P2→P1` 端点 j3 差 **170°**，是两支不同 IK 解；末端直线在 40 段内解不出连续路径（过肘奇异）
  → 只能关节 lerp，末端走一个高位弧（最低 z 0.950 m）。
- `P1→P0` 末端直线会把 j6 压到 **−41.0°**（限位 −42.1°，只剩 1.1° < 2° 失败线）
  → 必须关节 lerp。

## ⚠️ 已知局限（不要当成精密工具）

1. **URDF 的腕心/肘坐标不可信**。j5/j6/j7 在 URDF 里交于同一点，但算出的腕心与
   "法兰沿夹爪轴外伸 0.10926 m"自相矛盾（P0 处腕心比 TCP 低 39 cm）。
   因此碰撞检查**只查校准后的 TCP**，不查连杆。
2. **没有真正的碰撞体**。占位盒（x 0.42–0.80 / y −0.46–0.00 / z 0.70–1.05）是手工包的包围盒，
   只做 TCP 点判定。手臂连杆是否撞桌子，离线回答不了。
3. **无奇异检测**。只靠"相邻构型关节差 ≤15°"间接避开。
4. **FK 位置精度 17.4 mm**（姿态经常量修正后 ~2°）。所以位置一律用实测/标定值，
   不要拿原始 URDF FK 当真实末端位置。

## 实际验证情况（2026-11-08）

| 项 | 结果 |
|---|---|
| 离线规划 | 38 点 / 37 段，最大单步 15.0° |
| 真机 `home_to_carry --yes` | 22 段全部到位，右 0.09° / 左 0.12°（判据 3°），38.66 s |
| 真机实验 1 | **总状态 ok，10/10 步全过**，37 段最大回放前跨度 14.8°，回放后偏差 ≤0.17° |
| 端点实测 | START (0.255,−0.234,0.739) → P2 (0.390,−0.667,0.957) → P1 (0.546,−0.790,0.994) → P0 (0.562,−0.198,1.186) |

P0 处 j7 距限位仅 **4.4°**（告警线 5°），会打 WARNING —— 属预期，不是故障。
