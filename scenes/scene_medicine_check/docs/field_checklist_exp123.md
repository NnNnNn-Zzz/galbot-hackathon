## 零、开跑前先回答一个问题：药盒要准备什么数据？

结论先说：**实验 1 不需要，实验 2/3 只要几何，不要内容。**

| 实验 | 需要的药盒信息 | 不需要的 |
|---|---|---|
| 实验 1 空桌 | 无（桌上什么都不放） | 全部 |
| 实验 2 单盒 | 中心 x=0.40 m、y=-0.10 m、夹爪目标 z=0.77 m、**盒宽 7.5 cm** | 药名、批号、生产/过期日期、重量、材质 |
| 实验 3 全流程 | 同实验 2，**另加垃圾桶位置**（要现场示教） | 同上 |

**为什么不需要日期？**
基线是盲抓——不看图、不识别、不选目标，抓到哪个就是哪个（桌上只有一个）。
日期数据要等 VLM/OCR 版才用得上，而且那时是从相机图像里读出来的，不是从任何表格里读的。

**器械清单：**

| 项 | 说明 |
|---|---|
| 卷尺 | 量 x=40cm、y=10cm 用，两条胶带交点就是盒位 |
| 美纹纸胶带 | 贴两条定位线，别用会留胶的 |
| 卡尺或直尺 | 确认盒宽 ≤8 cm |
| 窄药盒 | 挑一个**最窄**的，宽了夹不住 |
| 垃圾桶 | 实验 3 用；高度以桶口在 z≈0.3–0.5 为佳 |
| 急停 | 实验 3 必须一人手持 |

## 二、实验 1 空桌盲抓（无盒）

**桌子必须清空** —— 包括盒子、纸片、卷尺。留东西会被 `is_holding()` 误判。

```bash
MED_IO=wrapper python3 scripts/run_exp1_grasp_only.py
```

**看着手臂，确认这五个动作（顺序固定，少了第 0 步就会重演上次的 FAULT）：**
0. **先到固定初始位** —— 先动腿，再动头部和双臂；右臂关节角换成调宽后的抱持角
1. 夹爪张开到约 10 cm
2. 移到 (0.35, -0.10, 0.85) —— 盒子**上方**
3. 直线下降到 (0.40, -0.10, 0.77) —— 桌面**上方 5 cm**
4. 夹爪闭合到 7.5 cm → 抬到 0.90 → 收臂回抱持位，目视肘部与身体间隙约 5 cm

**通过判据**（脚本会自己判）：
- `"passed": true`
- `"grabbed": false`（空桌抓空，**这才是对的**）
- 全程无碰撞、无急停

**不通过怎么办：**

| 现象 | 处理 |
|---|---|
| `passed=false` 且 `grabbed=true` | 桌上有东西没清干净，清空重跑 |
| `init_pose=failed`（`init_legs`） | **停下查腿**。腿部归位失败会让后续所有笛卡尔目标从错误基准出发，别去调抓取坐标 |
| `init_pose=failed`（`init_upper_body`） | **停下查上半身**。头部/双臂初始位没建立，抓取已被自动跳过，确认关节没卡住再重跑 |
| `grasp=failed`，报 `move_line_to` 失败 | 先确认上一条是 `init_pose=ok`；再按 `GRASP_POSE` z 每次 +0.01（上限 0.80），重跑 |
| `grasp=unknown` | **停手**。不发任何动作，人工把臂摆回安全位，报给我排查 |
| 明显撞桌 | 拍急停，抬 z 0.02 再试 |

## 三、实验 2 单盒盲抓

**摆盒（这一步决定成败，别省）：**

1. 从机器人底座**正前沿**往里量 **40 cm** → 贴一条**横向**胶带
2. 从底座**中线**往**右**量 **10 cm** → 贴一条**纵向**胶带
3. 盒子中心压在**交点**上，长边朝机器人（垂直于手臂伸出方向）
4. 用卡尺确认**盒宽 ≤ 8 cm**

```bash
MED_IO=wrapper python3 scripts/run_exp2_one_box.py
```

脚本开头会再打印一遍摆位说明（`placement` 字段），照它说的做。

**通过判据：**
- `"passed": true`
- `"grabbed": null` 是**正常的** —— 本后端读不到夹爪反馈，抓没抓住只能靠**你眼睛看**

**没抓住但流程走完了？** 这也算**链路通过**。按这个顺序调，不要跳步：

| 顺序 | 动作 | 幅度 |
|---|---|---|
| ① | 重新摆盒（xy 最容易错，90% 的问题在这） | 重贴胶带 |
| ② | 调 `GRASP_POSE` 的 z | 每次 ±0.01，范围 0.72–0.80 |
| ③ | 最后才动 x/y | 每次 ≤1 cm |

**改完任何一项，必须重跑实验 1 确认轨迹还安全。**

## 四、实验 3 全流程（必须先示教桶位）

### 4.1 先示教桶位（否则脚本会拒绝执行）

`tuning.py` 里的 `PRE_DROP_POSE` / `DROP_POSE` 现在是**占位值**，脚本有安全闸会拦住。

```bash
# 手动把右臂摆到桶口正上方约 5 cm，夹爪朝下
python3 scripts/teach_drop_pose.py              # 读 PRE_DROP

# 手动降到盒子刚好接触桶口的高度
python3 scripts/teach_drop_pose.py --tag drop   # 读 DROP
```

把两次打印的两行值，**原样粘贴**进 `scenes/scene_medicine_check/pipeline/tuning.py`，
替换掉带 `TODO(标定)` 的那两行。

**示教完再跑一次实验 3，闸门会自动放行。**

### 4.2 摆桶

桶必须放在**示教时那个位置**，跑之前不能挪。左移 0.5 m + 右转 30° 之后桶就在那儿。

### 4.3 跑

```bash
MED_IO=wrapper python3 scripts/run_exp3_full.py
```

脚本会先打印 8 步计划，然后**停下来等你按回车**，并列出确认清单：
急停在手边 / 桌面一盒 / 桶没动 / 周围无人。

**通过判据：**
- `"passed": true`
- 8 步全 `ok`（`preflight → init_pose → grasp → announce → shift_left → turn_bin → drop → home`）
- `"home_executed": true`

**故意测失败路径**（也建议做一次）：
跑到一半人为让它 failed（比如手挡一下），确认 `home` 仍然执行 —— 这是「失败也要归位」的现场验证。

## 七、每步之后要记什么

每次跑完记三行，攒够能看出趋势：

```
日期/时间 | 实验编号 | passed | grabbed | failed_step | 改了什么
```

`grabbed` 在真机上恒为 `null`（无夹爪反馈），所以要**另记一列「目视是否夹住」**。
